# Echo-3 Worlds — rules for this app

Added at the user's request as `displayxr-demos/apps/echo-worlds/` (like Physical AI Lab and Splat Call).

- Content is **streamed from SpAItial's public gallery**, never copied into the repo. Credit
  SpAItial on the page. Public use beyond this demo needs SpAItial's OK (asked in the proposal).
- Echo-3 worlds are **Y-up**: keep `flipY: false`.
- `worlds.json` is generated by `tools/echo3_frame.py` (plus the pick list in the commit that
  added it); regenerate rather than hand-edit floors and footprints.
- Rule zero: the room is fully in view at a middle size, the camera never inside it. Check a new
  world with `tools/echo3_sheet.py` and a headless screenshot before adding it.
- Report seated checks as Pass/Fail with runtime + plug-in version and depth %.
